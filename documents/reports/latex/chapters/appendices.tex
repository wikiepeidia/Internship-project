\chapter{Source Code and Project Artifacts}
\label{app:source-code}

The complete source code, dataset manifests, training configurations, and
evaluation artifacts produced in this project are maintained in the
project repository. The codebase is organised into three packages:
\texttt{src/data\_pipeline} for dataset construction, \texttt{src/runtime}
for the user-facing local inference server, and
\texttt{src/model\_adaptation} for the QLoRA fine-tuning and GGUF
conversion workflow. All entry points are documented in the repository
\texttt{README.md}.

The final GGUF inference artifact (\texttt{gguf-laptop.gguf}) and the
model registry pointing to the off-repository artifact root are not
included in the repository to avoid large binary uploads, but their
paths and SHA256 identifiers are recorded in
\texttt{data/manifests/model-registry.json}.
