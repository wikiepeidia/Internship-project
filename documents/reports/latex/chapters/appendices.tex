\section*{Appendix 1: Source Code and Project Artifacts}
\addcontentsline{toc}{section}{Appendix 1: Source Code and Project Artifacts}

The complete source code, dataset manifests, training configurations, and
evaluation artifacts produced in this project are publicly available at:

\begin{center}
\url{https://github.com/wikiepeidia/Internship-project}
\end{center}

The codebase is organised into three packages:
\texttt{src/data\_pipeline} for dataset construction, \texttt{src/runtime}
for the user-facing local inference server, and
\texttt{src/model\_adaptation} for the QLoRA fine-tuning and GGUF
conversion workflow. All entry points are documented in the repository
\texttt{README.md}.

The 4.28~GB GGUF inference artifact (\texttt{gguf-laptop.gguf}) and the
external model registry are not included in the repository. The small
final-evidence manifest records the artifact path, byte size, and SHA-256
identifier so that the deployed file can be checked without committing it.

\noindent\textbf{Reproducing the reported pipeline:} the same commands used to produce the artifacts cited throughout this thesis are:

\begin{center}
\small
\begin{tabular}{ll}
\toprule
\textbf{Step} & \textbf{Command} \\
\midrule
Check training readiness & \texttt{python -m src.model\_adaptation.cli doctor} \\
Run QLoRA adaptation & \texttt{python -m src.model\_adaptation.cli train} \\
Export to GGUF & \texttt{python -m src.model\_adaptation.cli convert} \\
Run held-out evaluation & \texttt{python -m src.model\_adaptation.cli evaluate-release-split} \\
Check runtime readiness & \texttt{vnphish doctor} \\
Analyze one message & \texttt{vnphish analyze} \\
\bottomrule
\end{tabular}
\end{center}

Each command accepts flags for artifact paths, hyperparameters, and evaluation split location; the defaults reproduce the reported run. This table is intentionally a list of real, runnable commands rather than a narrative description, so the pipeline can be checked directly against the repository rather than taken on the strength of this document alone.

\section*{Appendix 2: Dataset Class Distribution}
\addcontentsline{toc}{section}{Appendix 2: Dataset Class Distribution}

The labelled corpus contains 3,000 Vietnamese messages constructed from
cybercrime alert seeds (tinnhiemmang.vn) combined with synthetic
generation. Pydantic validates record structure, while a separate LLM-based
judge provides the recorded sample-quality scores. The corpus is split into
training, validation, and test partitions. Table~\ref{tab:dataset-splits}
summarises the final split sizes and Table~\ref{tab:validation-class-dist} shows
the per-class distribution of the 254-example validation set used for the
reported comparison.
