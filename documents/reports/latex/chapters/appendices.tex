\section*{Appendix 1: Source Code and Project Artifacts}
\addcontentsline{toc}{section}{Appendix 1: Source Code and Project Artifacts}

The source code, compact manifests, training configurations, verification receipts, and report assets are available at:

\begin{center}
\url{https://github.com/wikiepeidia/Internship-project}
\end{center}

The maintained application is organised by responsibility. \texttt{src/runtime} owns the installed text-analysis interface; \texttt{src/data\_pipeline} owns records, normalization, group-safe splitting, generation workflows, and a closed migration catalog; \texttt{src/modeling} exposes phase-neutral training, inference, evaluation, and evidence ports; and \texttt{src/artifacts}, \texttt{src/core}, and \texttt{src/source\_archiving} own neutral artifact access, integrity operations, and immutable source capture. \texttt{src/model\_adaptation} retains compatibility commands and the exact implementations that produced historical evidence. It should not be read as the forward application architecture.

The public application entry point is \texttt{vnphish}. The three installed commands are intentionally small:

\begin{center}
\small
\begin{tabular}{lp{8.5cm}}
\toprule
\textbf{Command} & \textbf{Purpose} \\
\midrule
\texttt{vnphish doctor} & Check local runtime and selected-artifact readiness. \\
\texttt{vnphish analyze} & Analyze one Vietnamese text message and render the structured result. \\
\texttt{vnphish demo} & Start the local browser demonstration over the same runtime service. \\
\bottomrule
\end{tabular}
\end{center}

The selected Qwen inference artifact is not stored in Git. Its portable verification receipt records a Q8\_0 file of 4{,}280{,}403{,}232 bytes with SHA-256
\begin{center}
\small\texttt{457f6f92d36a7d54da9916fd80a4028dcd055a653a015c4877370a0fea4d18ab}.
\end{center}
The receipt also binds the selected-checkpoint lineage and two load-smoke records. It verifies identity and materialization; it is not a substitute for committing the 4.28~GB file and does not claim a PhoBERT GGUF export.

The maintained architecture map and CLI contract catalog are listed in the evidence index. The current code review still records six critical and three warning findings, so these documents describe a substantially improved maintained structure, not a fully security-closed deployment.
