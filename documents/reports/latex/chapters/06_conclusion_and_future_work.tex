This thesis developed a local LLM pipeline for Vietnamese financial phishing detection. The system connects synthetic data construction, Pydantic schema constraints, QLoRA adaptation, GGUF deployment, and structured user-facing output in one reproducible prototype.

\section{Main Findings}
The final model is \texttt{Qwen3-4B-Instruct-2507}, adapted with 4-bit NF4 QLoRA on 2{,}333 training examples. On the 254-example internal validation split, the adapted model reaches macro F1 0.9625 and accuracy 0.9646, compared with macro F1 0.6702 for the same base model without adaptation. The nine remaining errors are all between scam subtypes; none cross the binary scam--benign boundary. The merged Q8\_0 GGUF is registered and has been verified through the CPU-only command-line runtime.

These results support two limited conclusions. First, parameter-efficient adaptation substantially improves this model on the project's validation rows. Second, the full local deployment path is technically feasible on the target laptop. The results do not establish performance on independent real-world traffic.

\section{Limitations}
The evaluation split was also used for validation during training and recovery decisions. It is therefore not an untouched holdout. A split audit found one seed group in training, validation, and test, so related synthetic patterns may occur across partitions. The reserved 413-example test split was not evaluated in the final run. These issues can make the measured improvement optimistic for unseen seed groups.

The corpus is synthetic-derived and Vietnamese-only. Version~1 accepts text only and does not process screenshots, QR codes, audio, or multi-turn conversations. Finally, the final classification run did not include a new human review of all generated explanations. The system should consequently be treated as an academic prototype rather than an autonomous safety tool.

\section{Future Work}
The first priority is to rebuild the split by seed group and evaluate once on an untouched, human-labelled test set. A larger test set should include difficult overlaps, especially Zalo or task-scam messages that mention banks and OTP codes. This would provide a more credible estimate of generalization and clarify the remaining subtype boundary.

The second priority is an independent human review of explanation grounding and recommendation quality. The review protocol should retain individual ratings so that inter-rater agreement and any statistical analysis can be reproduced.

The third priority is optional OCR preprocessing for screenshots. OCR output could feed the existing text contract without changing the QLoRA model or local privacy boundary, although the added component would require its own error analysis.
