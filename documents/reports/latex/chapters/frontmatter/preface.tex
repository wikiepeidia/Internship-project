\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
This thesis presents a pipeline for fine-tuning a local large language model (LLM) to detect Vietnamese financial phishing messages while preserving user privacy through on-device inference. The promoted dataset contains 2,097 Vietnamese messages constructed from cybercrime alert seeds, synthetic generation, Pydantic schema validation, final joined judge evidence, targeted human triage, and lineage governance. The judge records 1,395/2,097 passes (66.52\%); a separate 100-row human sample records 44 PASS and 87/100 human--judge agreement. Qwen3-4B-Instruct-2507 is adapted using quantized low-rank adaptation (QLoRA) and deployed as a GGUF Q8\_0 artifact for CPU-based laptop inference via llama.cpp. A structured decision layer returns a risk tier, threat label, grounded evidence cues, and safety recommendations. On a 254-example internal validation split from the earlier training snapshot, the adapted model yields macro F1 0.9625, compared with 0.6702 for the same base model without adaptation. This historical result is limited by validation reuse and seed overlap and was not recomputed on the promoted corpus; it is not an independent test estimate. Deployment in safety-critical settings is not recommended without evaluation on a real-world labelled corpus.

\vspace{0.5em}
\noindent\textbf{Keywords:} Vietnamese phishing detection; local large language models; explainable artificial intelligence; QLoRA adaptation; GGUF inference; financial fraud prevention.
