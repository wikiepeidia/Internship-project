        {\footnotesize
        \begin{enumerate}
          \setlength{\itemsep}{0.2em}
          \item \textbf{Train in 4-bit NF4:} keeps frozen base weights small enough for GPU fine-tuning.
          \item \textbf{Merge adapter:} fold the learned LoRA adapter back into the model.
          \item \textbf{Export as GGUF Q8\_0:} run locally on CPU with better quality than very low-bit export.
