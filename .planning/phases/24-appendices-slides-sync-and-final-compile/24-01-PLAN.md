# Phase 24 Plan 01: Appendices, Slides Sync, and Final Compile

## Goal

Add appendices section to thesis, scan defense slides for stale "Chapter X" references, and produce a clean final XeLaTeX compile.

## Tasks

### Task 1 — Add appendices section

- Add `\appendix` block to `main.tex` after bibliography
- Set `\titleformat{\chapter}` for "APPENDIX A" style heading
- Create `chapters/appendices.tex` with Appendix A (Source Code) and Appendix B (Binary Evaluation Raw Results)

### Task 2 — Scan slides for stale Chapter references

- Grep all `documents/reports/latex/slides/sections/*.tex` for "Chapter~" and "Chapter [0-9]" patterns
- Fix any found references; if none, record SYNC-01 as satisfied with no changes

### Task 3 — Final XeLaTeX compile

- Delete aux files
- Run XeLaTeX → BibTeX → XeLaTeX → XeLaTeX (4 passes)
- Verify zero fatal errors in main.log
- Verify page count and section numbering visually

## Acceptance Criteria

- `chapters/appendices.tex` exists with at least one labelled appendix
- Slides grep returns zero "Chapter~N" matches
- Final PDF compiles clean — zero errors, correct numbering
