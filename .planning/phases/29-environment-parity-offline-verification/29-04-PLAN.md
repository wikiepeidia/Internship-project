<objective>
Prove the demo's offline claim by actually disabling network connectivity on this machine and running the two locked Phase 28 golden prompts (scam + benign) through the real web demo — not a grep-only or DevTools-only inference. This is the one requirement in this phase that structurally cannot be an autonomous agent task: the agent's own session depends on the same network path being cut, and netsh-based adapter toggling requires Administrator elevation this shell does not have. 29-RESEARCH.md's Pattern 4 documents this as a hard constraint, not a convenience choice.

Purpose: ENV-02 is a claim that will be stated to the defense committee ("this demo works fully offline"). D-05 explicitly rejects a lighter proof; the network must actually be cut, with DevTools Network tab confirmation as a secondary check afterward, not a replacement.
Output: a pre-filled runbook artifact with the exact locked prompts embedded, a human-executed offline test, and a final evidence record combining the human-reported verdicts, the DevTools confirmation, and a post-test doctor re-confirmation.
</objective>
