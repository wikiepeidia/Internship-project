<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output -> structured payload | untrusted local generation must be validated before it reaches the public contract |
| deterministic safety helper -> final decision | helper logic can only floor risk and support grounding; it must not become the primary backend |
| richer parsed output -> privacy-safe error path | validation and repair failures must not leak message text or raw model output |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Integrity | src/runtime/analyzers/local_model.py | mitigate | Validate risk tier, label vocabulary, and recommendation fields with one shared schema before mapping to `AnalysisResult`. |
| T-04-02-02 | Tampering | src/runtime/analyzers/rules.py | mitigate | Use deterministic cue rules only as a bounded safety floor and grounding helper; do not route Phase 4 decisions back through heuristic-only scoring. |
| T-04-02-03 | Information Disclosure | tests/runtime/test_privacy.py | mitigate | Extend privacy regressions so richer parsing failures and sanitized recommendations never echo raw message text or raw model output. |
| T-04-02-SC | Tampering | shared decision parsing | mitigate | Keep the schema compact and deterministic; allow at most bounded repair behavior instead of unstructured retries. |
</threat_model>
