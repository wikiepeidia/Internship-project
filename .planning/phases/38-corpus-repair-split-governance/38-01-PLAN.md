    Implement all five functions in a new module `src/data_pipeline/repair_corpus_split_governance.py`.
    `pool_records(paths: list[Path]) -> list[dict]` reads and concatenates JSONL rows (via `json.loads` per line) from the given file paths in the given order, returning plain dicts (no `DatasetRecord` validation yet — validation happens at write time).
    `repair_evidence_spans(record: dict) -> dict | None` iterates `record["suspicious_spans"]`: keep a span unchanged if `span in record["text"]` (exact substring, per CONTEXT.md's locked exact-substring validation rule); else search case-insensitively via `record["text"].lower().find(span.lower())` and if found (index >= 0), replace that span with `record["text"][index:index+len(span)]` (the exact-cased substring); else drop that span entirely. After processing every span, if the resulting `suspicious_spans` list is empty, return `None`; otherwise return a shallow copy of `record` with `suspicious_spans` replaced.
    `repair_all_evidence_spans(records: list[dict]) -> tuple[list[dict], dict]` calls `repair_evidence_spans` per record, returning the surviving records plus `{"rows_pooled": len(records), "rows_span_repaired": <count where output spans != input spans>, "rows_dropped_unrecoverable_span": <count where repair_evidence_spans returned None>}`.
    `enforce_seed_cap(records: list[dict], cap_pct: float = 0.08) -> tuple[list[dict], dict]` groups records by `seed_id`, then iteratively: recompute each remaining seed_id's share of `len(records)` (the CURRENT total, recomputed after every trim since trimming shrinks the denominator — per 38-RESEARCH.md's cap-arithmetic note), and for the seed_id with the largest over-cap share, call `lexical_dedup(group_records, threshold=0.95)` from `processing/dedup.py` to identify near-duplicates, order the deduped survivors deterministically (e.g. by `_stable_bucket(record["text"], salt)` imported from `processing/splitter.py`), and truncate to `int(cap_pct * current_total)` rows, dropping the remainder; repeat until no seed_id exceeds `cap_pct`. Return the final record list plus a stats dict `{"seed_concentration_before": {seed_id: pct, ...}, "seed_concentration_after": {seed_id: pct, ...}, "rows_dropped_seed_cap": N}` covering every seed_id that was ever over cap during the process.
    `assign_stratified_group_split(records: list[dict], ratios: tuple[float, float, float] = (0.8, 0.1, 0.1), salt: str = "phase38-corpus-repaired-v2") -> dict[str, str]` groups records by `seed_id`, computes each of the four labels' ACTUAL global proportion across the input `records` (not a hardcoded 25% — per 38-RESEARCH.md Open Question 2), orders seed_ids deterministically via `sorted(seed_ids, key=lambda sid: (_stable_bucket(sid, salt), sid))` (imported `_stable_bucket` from `splitter.py`, never `random.shuffle`), then greedily assigns each seed_id's whole row-group to whichever of train/val/test currently minimizes the resulting deviation from those observed global per-class proportions, subject to each split's running row-count staying near its `ratios`-derived target (model this on 38-RESEARCH.md Pattern 2's pseudocode, adapting the budget-tolerance and scoring to real data). Every row of a given seed_id MUST go to the same split — no per-record splitting.

    `main()` wires an `argparse.ArgumentParser` (flags: `--input-main` default `data/synthetic/recovered-balanced.jsonl`, `--input-reserved` default `data/splits/recovered-balanced/test.jsonl`, `--output-dir` default `data/splits/phase38-corpus-repaired-v2`, `--version-tag` default `phase38-corpus-repaired-v2`, `--cap-pct` default `0.08`, `--split-ratios` default `0.8,0.1,0.1`) that runs `pool_records` -> `repair_all_evidence_spans` -> `enforce_seed_cap` -> `assign_stratified_group_split` -> writes each split's rows as `DatasetRecord.model_validate(record).model_dump()` JSONL to `{output_dir}/{split_name}.jsonl` -> computes per-split per-class counts -> calls `build_repair_manifest` -> writes the composed manifest dict to `data/manifests/manifest-{version_tag}.json` via `json.dump` -> prints a summary.
