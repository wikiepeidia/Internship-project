## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| split files -> release readiness audit | held-out support claims are untrusted until counted against the full locked label set |
| typed Phase 5 contracts -> later evaluator and gate plans | verdicts, metrics, and rubric summaries must stay explicit and stable across all later work |
| current split naming -> release policy | filenames like `train/val/test` must not be treated as proof of all-label held-out support |
