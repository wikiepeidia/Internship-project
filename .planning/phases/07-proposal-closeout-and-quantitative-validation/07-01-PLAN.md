# Phase 7 Plan 01: Final dataset closeout and split freeze

Objective: produce one final validated dataset artifact in the 2,500-3,000 target band and freeze seed-disjoint train, validation, and test splits with held-out support for all in-scope labels.

Must haves:

- The final dataset lineage must end in one validated JSONL artifact, not a blend of counts from multiple intermediate files.
- The remaining Claude API budget should be spent only on targeted missing-class generation or judging work that improves final validated yield.
- The frozen split set must include non-zero held-out support for `bank_impersonation`, `zalo_social_engineering`, `task_scam`, and `benign` in the final evaluation path.
- The resulting manifest must make the dataset and split lineage reproducible on another machine.

Artifacts:

- `data/processed/validated.jsonl` is refreshed to the final closeout dataset artifact.
- `data/processed/quality-stats.json` records the final judged dataset statistics.
- `data/splits/train.jsonl`, `data/splits/val.jsonl`, and `data/splits/test.jsonl` are frozen for the closeout milestone.
- `data/manifests/manifest-proposal-closeout.json` records the final dataset lineage and split outputs.

Verification:

- `python -m src.data_pipeline.cli --seed-input data/raw/seeds-2026-04-24.jsonl --target-count 3000 --version-tag proposal-closeout --resume`
- `wc -l data/processed/validated.jsonl data/splits/train.jsonl data/splits/val.jsonl data/splits/test.jsonl`

Success criteria:

- One validated dataset artifact exists in the 2,500-3,000 JSONL target band.
- The frozen split set is reproducible and non-empty across train, validation, and test.
- The final evaluation path is no longer blocked by zero held-out support for risky labels.
