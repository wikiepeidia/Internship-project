Inside Beamer frames, the \begin{figure}[H] and \begin{table}[H] wrappers from thesis files will cause "float not allowed in this context" errors. Wrap each \input{} inside a \begin{center}...\end{center} block or remove the float environment using a redefinition trick. The safest approach is to redefine the figure and table environments to be no-ops before the frame and restore after:

  \makeatletter
  \let\real@figure\figure
  \let\endreal@figure\endfigure
  \renewenvironment{figure}[1][]{\begin{center}}{\end{center}}
  \let\real@table\table
  \let\endreal@table\endtable
  \renewenvironment{table}[1][]{\begin{center}}{\end{center}}
  \makeatother

  ... \input{figures/...} ...

  \makeatletter
  \let\figure\real@figure
  \let\endfigure\endreal@figure
  \let\table\real@table
  \let\endtable\endreal@table
  \makeatother

Use \scalebox{0.62}{...} around the \input to scale figures down to fit 16:9 frames (test value; adjust if content overflows). For the confusion matrix use \scalebox{0.75}{...} and \footnotesize inside the scalebox.

CVBLUE is already defined in slides/preamble/colors.tex — no need to redefine in section files.
