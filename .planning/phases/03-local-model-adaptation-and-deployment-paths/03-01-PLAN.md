<threat_model>

- Asset: the candidate catalog and pilot results define which checkpoints later receive expensive training and runtime integration effort.
- Threat: checkpoint choices stay informal in chat only, leading to irreproducible winner/runner-up selection and plan drift.
- Threat: artifact metadata gets stored ad hoc and diverges from the checksum discipline already used by the Phase 1 dataset pipeline.
- Threat: the pilot layer quietly introduces a second risk-tier vocabulary or a second runtime contract surface.
- Required control in this plan: encode candidate selection, pilot outputs, and artifact registry state as typed local metadata with deterministic tests and checksum-backed persistence.
</threat_model>
