<interfaces>
The phase introduces one primary experiment identity: `ExperimentIdentity(model_family, adaptation_mode, run_kind)`.
Supported tuples are exactly Qwen with `lora` or `qlora` for `probe` or `full`, plus PhoBERT with `classification-head` for `full`. PhoBERT with LoRA/QLoRA, Qwen with a classification head, and PhoBERT probes are rejected as impossible combinations.

The canonical input API is `preflight_phase40_inputs(train_path, val_path, *, repo_root) -> Phase40DataContract`. It has no third split or caller-controlled authority parameter. After reject-before-open authorization and whole-file identity checks, it returns ordered train then validation identities plus immutable `CanonicalSplitSnapshot` values in canonical file order. Each split snapshot retains its exact authorized whole-file byte string and SHA-256 for byte-for-byte transfer without reopening or JSON reserialization. Each `CanonicalSnapshotRow` retains the exact JSONL record bytes excluding only a terminal `LF` or `CRLF`, the parsed `DatasetRecord`, `raw_message=record.text`, `source_row_sha256=sha256(exact_record_bytes)`, logical split, zero-based canonical index, and one derived row ID. The exact derivation is `"p40-row-v1-" + sha256(b"phase40-snapshot-row-id-v1\\0" + split_name.encode("ascii") + b"\\0" + str(canonical_index).encode("ascii") + b"\\0" + bytes.fromhex(source_row_sha256)).hexdigest()`. The split name and index make repeated byte-identical rows distinct; the record digest makes byte mutation visible. `validation_row_id` is the resulting ID for a `val` snapshot row and is the sole validation join key used downstream. The Phase 39 authority relative path is a private module constant; its lexical identity is proved against the one canonical repository-relative value before it can be opened.

The validation API consumes ordered gold rows and raw prediction rows. `generate_qwen_validation_predictions` calls `model.generate` with a typed immutable decoder contract (`do_sample=False`, `num_return_sequences=1`, `max_new_tokens=256`), persists one ordered raw JSONL row per validation ID, and never repairs output. Qwen prediction state is one locked label or `invalid_output`; PhoBERT uses the same evaluator with no invalid predictions under normal logits.
</interfaces>
