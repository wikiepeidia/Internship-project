<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Measurement script -> local subprocess | The script owns a `vnphish demo` process and must terminate only that owned process handle. |
| Browser -> loopback demo server | Playwright drives the same local browser/UI path as the user-facing demo, bound to `127.0.0.1`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-30-01 | Denial of Service | Script-owned `vnphish demo` subprocess | mitigate | Terminate the owned process in `finally`, with wait/kill fallback. Never pattern-kill unrelated `python` or `vnphish` processes. |
| T-30-02 | Tampering | Evidence artifact labeling | mitigate | Evidence runs require `--post-reboot-confirmed`; diagnostic runs are labeled diagnostic and cannot satisfy PERF-01. |
| T-30-03 | Information Disclosure | JSON artifacts | accept | Artifacts contain the already-locked synthetic demo prompts and timing/power metadata only; no secrets or raw model paths beyond existing local evidence scope. |

</threat_model>
