## Summary

The iteration-2 fixes close the exact open, native-symbol, keyword-route,
PowerShell-deletion, CLI-secret, and IPv6 examples that were added to the suite.
The exact guarded six-file gate passed **128 tests in 7.46 seconds** with pytest
plugin autoload disabled.

The implementation is still not clean. Broader adversarial probes found protected
filesystem originals and native capabilities outside the asserted boundary, a
collection-time attestation gap, and five valid route forms that still return an
empty inventory. The local demo and terminal renderer also expose security defects
inside the explicit review scope. No protected authority, model, provider,
evaluation, training, or inference resource was accessed during this review.

## Critical Issues

### CR-01: Recovered non-open filesystem originals bypass the audited boundary

**Classification:** BLOCKER

**File:** `tests/architecture/bootstrap/sitecustomize.py:174-250,336-377`; `tests/architecture/test_provenance_boundary.py:120-153`

**Issue:** Every path wrapper still closes over its original callable, but the
append-only audit map covers only a subset of filesystem operations. The regression
recovers and tests `_io.open` only. A caller can walk the `os.stat`, `os.access`, or
`os.lstat` wrapper closure and invoke the original; those operations have no mapped
independent audit denial. The Python guard therefore does not enforce the declared
protected-root boundary for all operations it claims to guard.

**Fix:** Put the exact architecture runner behind an independently enforced
filesystem boundary that denies all seven roots even when original callables are
recovered. Keep the Python wrappers as defense in depth and add recursive
adversarial recovery tests for every installed path operation. If no external
boundary is available, narrow the claimed protection and do not treat this runner
as sufficient for protected-root safety.

### CR-02: Undeclared pre-created native handles remain usable

**Classification:** BLOCKER

**File:** `tests/architecture/bootstrap/sitecustomize.py:28-44,112-126,391-413`; `tests/architecture/test_provenance_boundary.py:286-338`

**Issue:** The guard patches loader constructors and
`ctypes.LibraryLoader.__getattr__`, then scrubs four loader instances. It does not
deny or inventory the already-created `ctypes.pythonapi` `PyDLL(None)` handle or
inherited `CDLL`/`PyDLL` symbol-resolution surfaces. Consequently, the assertion
that only six documented preloaded native file-binding calls remain is false.

**Fix:** Inventory every pre-existing DLL handle and symbol-resolution route before
collection. Deny or scrub all non-required handles and inherited lookup methods,
then compare the remaining function objects against one independent exact six-item
allowlist.

### CR-03: Collection attestation can pass with an incomplete guard

**Classification:** BLOCKER

**File:** `tests/architecture/conftest.py:13-41`; `tests/architecture/test_provenance_boundary.py:17,68-118`

**Issue:** `conftest.py` checks only that the native disposition map has ten values
from an allowed vocabulary. It does not compare exact native keys, attest the 53
process symbols and wrapper markers, or verify the six native capabilities. Test
modules import source code during collection before the later test assertions run,
so guard drift can execute reviewed imports before it is detected.

**Fix:** Move an independent exact 7-root, 53-process, native-surface, wrapper-marker,
and six-capability attestation into `conftest.py` before test-module collection.
Abort collection on any missing, extra, stale, or incorrectly wrapped entry.

### CR-04: Tool-route discovery remains fail-open for valid execution statements

**Classification:** BLOCKER

**File:** `tests/architecture/test_architecture_policy.py:663-681,695-915,1038-1094`

**Issue:** The parser now handles keyword `args=` and line-leading `start`, but it
still ignores callable assignment aliases and compound commands. Guarded in-memory
probes returned `[]` for all of these executable forms:

```text
runner = subprocess.run; runner([...])
echo ready & unsafe.exe --flag
cd . & unsafe.exe --flag
Write-Host ready; Start-Process python -ArgumentList '-V'
echo ready; python -m src.runtime.cli demo
```

The PowerShell and Bash special branches can likewise return after finding their
expected route without rejecting extra statements. A real execution edge can thus
be added while the frozen tool inventory remains green.

**Fix:** Parse complete statements, pipelines, control operators, and simple
callable aliases before special-case extraction. Maintain a closed builtin grammar
per language and reject every unmatched command node. Add all five demonstrated
mutations and exact route assertions.

### CR-05: The loopback demo accepts drive-by and DNS-rebinding requests

**Classification:** BLOCKER

**File:** `src/runtime/demo.py:76-149`

**Issue:** `DemoApp` does not validate `Host` or `Origin` and accepts JSON bytes
without requiring `application/json`. A remote page can issue a browser-simple
`text/plain` POST to the loopback endpoint and trigger local inference. DNS
rebinding can additionally make the response same-origin because the attacker host
is accepted unchanged.

**Fix:** Bind the expected host into `DemoApp`, reject non-loopback or unexpected
`Host` values, require a same-origin `Origin` for POST (or a per-launch CSRF token),
and require `Content-Type: application/json`. Add hostile Host, foreign/missing
Origin, and simple-content-type tests.

### CR-06: Untrusted model/message text can inject terminal control sequences

**Classification:** BLOCKER

**File:** `src/runtime/contracts.py:14-18,45-55`; `src/runtime/render.py:20-56`

**Issue:** Summary, cue span/reason, recommendations, and error text are rendered
verbatim. A pasted phishing message or local-model response containing CSI/OSC or
other C0/C1 controls can manipulate the terminal, including OSC clipboard escape
sequences.

**Fix:** Apply one terminal-safe escaping function to every untrusted rendered
field while preserving ordinary Unicode and line structure. Add CSI, OSC, carriage
return, backspace, and embedded-control regression cases.

## Warnings

### WR-01: Report safety scanning still misses common shell chains

**Classification:** WARNING

**File:** `tests/architecture/test_report_handoff.py:80-88,174-213`

**Issue:** Command segmentation handles `&&`, `||`, and `;`, but not single `&` or
pipe chains. It accepts forms such as `echo safe & del /q candidate` and
`echo safe | rm -rf candidate`; alternate wrapper switches and line-continuation
secret assignments also remain unclassified.

**Fix:** Tokenize each supported shell grammar or reject every unclassified wrapper,
operator, and continuation. Add exact single-ampersand, pipe, `cmd /k`, `pwsh -c`,
and continued API-key mutations.

### WR-02: Demo host/port validation can advertise an unusable endpoint

**Classification:** WARNING

**File:** `src/runtime/demo.py:158-188`; `src/runtime/cli.py:66-72`; `tests/architecture/test_runtime_demo.py:82-86`

**Issue:** `rstrip('.')` accepts malformed names such as `localhost..`; the port has
no 1..65535 validation; and the URL is printed/opened before the server binds. Port
zero is advertised literally instead of using the assigned ephemeral port.

**Fix:** Accept and normalize only `localhost` (optionally one trailing dot), enforce
the selected port policy, create/bind the server before printing or opening the URL,
and use `server.server_port` when ephemeral binding is allowed.

### WR-03: Guarded pytest startup depends on an unstated environment switch

**Classification:** WARNING

**File:** `tests/architecture/bootstrap/sitecustomize.py:22-44,400-413`; `tests/architecture/conftest.py:13-41`

**Issue:** Without `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1`, the exact review command
crashes before collection when an installed plugin imports Click, which requests
`ctypes.windll.kernel32.GetStdHandle` after the guard replaces `kernel32` with its
six-member namespace. The successful gate silently depended on disabling plugin
autoload.

**Fix:** Provide one reviewed launcher that sets and attests
`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1` before Python startup, or preserve safe console
capabilities without enlarging the native authority boundary. Document the exact
guarded command.
