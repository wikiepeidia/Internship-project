| Phase 40 comparison/review evidence -> model protocols | Development-selected model identities become immutable inference protocols without consulting held-out outcomes. |
| Human authorization -> protected machine claim | An explicit decision crosses into an irreversible machine-wide spent record. |
| Protected claim -> sole OS handle | Claim durability must precede the only data access and survive every later failure. |
| Shared in-memory cohort -> model adapters | Text reaches both predictors while gold labels, source coordinates, and the other model's output remain hidden. |
