<threat_model>

- Asset: the analyze path must remain local-only and memory-only while still returning a usable provisional result.
- Threat: heuristic matching lowercases or rewrites the user-visible text, causing cue spans to stop matching the displayed string and breaking D-10.
- Threat: implementation imports network-facing modules or adds a cloud rescue path when the local backend fails, violating D-09 and RUN-01.
- Threat: service code writes the submitted message to disk, temp files, logs, or debug output while handling errors.
- Required control in this plan: keep analysis in `src/runtime/`, normalize once, match on a shadow copy, quote from normalized text, and make privacy assertions executable in `tests/runtime/test_privacy.py`.
</threat_model>
