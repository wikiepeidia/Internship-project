<threat_model>

- Asset: the CLI is the public Phase 2 entry surface, so its default behavior defines the privacy promise users actually experience.
- Threat: adding extra modes or flags turns the tool into a batch/file workflow and violates the one-message-per-run decision.
- Threat: the doctor command drifts into cloud/API-key advice, suggesting remote fallback that Phase 2 explicitly forbids.
- Threat: analyze errors echo the submitted text or skip readiness checks, making the local-only guarantee fragile in failure paths.
- Required control in this plan: keep the command surface to `analyze` and `doctor`, run the same readiness logic from both paths, and make tests assert exact return codes and guidance strings.
</threat_model>
