## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Tampering | i18n.js string values injected into DOM | accept | textContent assignment is not parsed as HTML; XSS via textContent is not possible. No user-controlled input reaches I18N values — all strings are compile-time constants. |
| T-15-02 | Information Disclosure | /static/i18n.js route | accept | File contains only UI label strings, no secrets, no PII, no model paths. Same threat model as /static/demo.css and /static/demo.js already served. |
| T-15-03 | Denial of Service | _load_asset("i18n.js") path traversal | accept | _load_asset constructs the path as ASSET_DIR / name with a hardcoded literal "i18n.js" — no user-controlled path component exists. Same pattern as existing demo.css and demo.js routes. |
| T-15-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this phase. Package Legitimacy Gate is not applicable. |
</threat_model>
