<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> local WSGI demo | Playwright sends untrusted UI text through the same `/api/analyze` boundary used by a real presenter. |
| Verifier -> filesystem artifacts | Browser telemetry and case results are persisted to phase-local JSON evidence. |
| Verifier -> subprocess | The script starts and stops a local `vnphish demo` subprocess and must not leave it running. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-31-01-I | Information Disclosure | `scripts/verify_ui_quirks.py` artifact writer | medium | mitigate | Store case names, lengths, classifications, counts, and deliberate fixture identifiers; avoid persisting arbitrary raw user-entered text beyond locked fixtures and deterministic test payloads. |
| T-31-01-D | Denial of Service | Very-long and double-submit verifier cases | medium | mitigate | Use bounded text length, Playwright timeouts, per-case failure records, and subprocess termination/kill in `finally`. |
| T-31-01-T | Tampering | Browser verifier path | medium | mitigate | Drive the real UI and frozen `/api/analyze` route; do not use direct service calls or edit backend contracts in this plan. |
| T-31-01-SC | Tampering | Package supply chain | low | accept | No package-manager install is planned; use existing Playwright/pytest dependencies already audited in `31-RESEARCH.md`. |
</threat_model>
