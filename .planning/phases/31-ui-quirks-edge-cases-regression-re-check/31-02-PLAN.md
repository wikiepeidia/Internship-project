<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator -> CLI | A presenter or committee helper chooses a command or launcher under time pressure. |
| Batch launcher -> shell | `.bat` files execute commands through `cmd.exe` from a double-click surface. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-31-02-S | Spoofing | CLI/launcher naming | medium | mitigate | Use explicit launcher names and help text that distinguish browser demo from terminal text analysis. |
| T-31-02-T | Tampering | `.bat` launcher command construction | medium | mitigate | Run fixed `python -m src.runtime.cli ...` commands from repo root; do not expand pasted message content into a shell command. |
| T-31-02-E | Elevation of Privilege | `.bat` launchers | low | mitigate | Do not request elevation, write registry keys, or change permanent environment variables. |
| T-31-02-SC | Tampering | Package supply chain | low | accept | No dependency installation is planned; argparse and batch files use existing stdlib/OS behavior. |
</threat_model>
